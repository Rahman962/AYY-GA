Vanliga prefix

Ett prefix står framför ett ord och kan ändra eller förstärka ordets betydelse.

o-

betyder ofta "inte"

lycklig → olycklig

miss-

något som görs fel

förstå → missförstå

över-

för mycket eller ovanför

driva → överdriva

under-

för lite eller nedanför

utvecklad → underutvecklad

för-

kan ändra betydelsen på olika sätt

stå → förstå

sam-

tillsammans

arbete → samarbete
